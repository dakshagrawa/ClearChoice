# ClearChoice voluntary beta feedback template

Feedback is voluntary and external. There is no feedback collection by the extension.

Send only this sanitized format:

```text
Rule: R1 | R2 | opt-in | revoke | history | subscription CRUD | guide | unsupported/restricted-page result
Expected: what you expected the extension to report
Actual: what the extension reported
Browser: Chromium version
```

Do **not** send any of the following:

- URLs
- screenshots
- personal information
- address information
- card or payment information
- order information
- receipt information
- page content

Do not include copied visible text, titles, HTML, form values, account information, or identifying details. A feedback report is not a request for a legal, compliance, safety, or deceptive-site conclusion.

For `0.4.0-beta.1`, describe expected/actual states without origin names, merchant names, subscription amounts, notes, local record exports, or identifying details. Do not send guide destinations or browsing history. Permission-harness success is not human-consent evidence.
